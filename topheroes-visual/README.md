# Novo contexto: jogo 2D

Pasta independente para um novo jogo 2D inspirado no estilo visual de Top Heroes: perspectiva isométrica, personagens em sprites, cenários coloridos e interface pensada para celular.

Esta etapa prepara apenas as dependências; a implementação do jogo será feita aqui nas próximas etapas. Os arquivos do jogo anterior ficam preservados.

## Dependências

- PixiJS: renderização 2D de sprites, cenários e animações no navegador.
- Vite: servidor de desenvolvimento e build do futuro projeto.
- TypeScript: suporte ao desenvolvimento com tipagem; PixiJS inclui seus próprios tipos.

## Instalação

Requer Node.js 22.12 ou superior.

```sh
cd /workspace/portaldangeon/topheroes-visual
npm ci --cache /tmp/topheroes-npm-cache
```

Ainda não há comandos para iniciar ou compilar o jogo, pois sua implementação não começou. O arquivo de lock fixa as versões instaladas. `node_modules` não é enviado ao GitHub.

Usar personagens, modelos e texturas próprios ou licenciados; Top Heroes é apenas uma referência de direção visual.
